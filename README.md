# Sumit Patel - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, and journey as a Full-Stack Developer and aspiring Machine Learning Engineer.

🔗 **Live Demo:**  
https://sumit-patel-portfolio.vercel.app/

---

## 🚀 Features

- **About Me:** Introduction to my background, current focus in ML/AI, and continuous learning journey.
- **Skills Section:** Technical skills categorized by Core Languages, ML Libraries, Frontend, Backend, Databases, Cloud/Deployment, and Tools.
- **Projects Showcase:** Interactive project cards with descriptions, technology stacks, and links to live demos and GitHub repositories.
- **Contact Integration:** Built-in contact capabilities using EmailJS.
- **Scroll Animations:** Smooth scroll-reveal effects implemented through custom React hooks.

---

## 🛠️ Technologies Used

- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Email Service:** EmailJS

---

## 📂 Featured Projects

### 🔹 Rankmate
A web application that processes college result ledgers (PDF) and converts them into ranked Excel files.

**Tech Stack:** Python, Flask, pdfplumber

---

### 🔹 Trading Bot
A Python trading bot connected to Binance Futures Testnet utilizing the Binance API and Plotly for visualizations.

**Tech Stack:** Python, Binance API, Plotly

---

### 🔹 Math Score Predictor
A machine learning model deployed via Flask that predicts student exam performance based on demographic and academic features.

**Tech Stack:** Python, Flask, Scikit-learn

---

### 🔹 Trading Behaviour
A data analysis project applying KMeans clustering on over 211,000 trading transactions to map trader performance against market sentiment.

**Tech Stack:** Python, Pandas, Scikit-learn, Matplotlib

## 💻 Getting Started Locally

### Prerequisites

Make sure you have Node.js installed on your machine.

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/sumitpatel-2322/Sumit-Patel-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Sumit-Patel-Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```bash
http://localhost:5173
```
